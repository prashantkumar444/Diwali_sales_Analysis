# Diwali Sales Analysis

## Project Overview
This project focuses on analyzing Diwali Sales data using Python in jupyter Notebook.The dataset was initially available in Excel format and was imported into python for data analysis and visualization.

The project explores different aspects of sales data to identify patterns and understand sales performance across various categories.

##Objective
The main objective of this project is to perform exploratory data analysis on Diwali Sales data and understand different sales patterns using python.

##Dataset
The dataset was provided in Excel format and imported into Jupyter Notebook for analysis.

##Tools and Technologies
- Python
- Jupyter Notebook
- Excel

##Python Libraries Used
- Pandas
- Numpy
- Matplotlib
- Seaborn

##Analysis Performed
The following analysis were performed as part of the project:
-Imported and explored the sales dataset
-Analyzed sales based on gender
-Analysed sales by states 
-Calculated the percentage of different payment modes
-Created visualizations to understand the analyzed data
-Used charts and graphs to present sales patterns 

##Visualizations
The project includes visualization for different aspects of the sales data,including:
- Sales by gender
- Sales by states 
- Payment Mode Percentage 
- Other sales related analysis and visualizations

## Conclusion
This project provided practical experience in using Python Libraries such as Pandas,Numpy ,Matplotlib,and Seaborn for data analysis and visualization .
It also helped in understanding how Raw Excel data can be imported ,analyzed, and visualization using python.
